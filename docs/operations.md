# Эксплуатация PromVector Agent

## Установка

Артефакты сборки доступны в разделе Actions после успешного выполнения задачи `desktop`. Каждый файл собирается на целевой операционной системе.

- **Windows x64.** Запустите `PromVector-Agent-Setup.exe` от пользователя, который будет собирать данные. Установка выполняется для текущего пользователя. Автозапуск можно включить в установщике. Портативный `PromVector Agent.exe` запускается самостоятельно. Целевые системы — Windows 10 1809+ и Windows 11.
- **macOS Apple Silicon.** Распакуйте ZIP и перенесите `PromVector Agent.app` в «Программы». Для автозапуска добавьте приложение в «Объекты входа».
- **Linux x64.** Распакуйте архив, сохраните право исполнения и запустите `PromVector Agent`. Сборка на Ubuntu 24.04 использует системные библиотеки Qt. Для автозапуска можно добавить приложение в настройки запуска текущей графической сессии.

Сборки CI без сертификата издателя и нотариального заверения предназначены для проверки. Перед организационным развёртыванием подпишите файлы своим сертификатом и проверьте запуск на образе ОС предприятия.

```sh
uv sync --locked --extra package
uv run python scripts/build.py
```

На Windows для установщика запустите `ISCC.exe installer\windows.iss` с установленным Inno Setup 6. На macOS для ZIP запустите `ditto -c -k --keepParent "dist/PromVector Agent.app" dist/PromVector-Agent-macOS.zip`. Инструмент упаковки использует платформу сборки. [Документация PyInstaller](https://www.pyinstaller.org/en/stable/usage.html)

## Работа без открытого окна

При включённой настройке фоновой работы закрытие окна оставляет процесс в трее. Выберите «Завершить» в меню трея для корректной остановки. Для запуска из исходников без окна используйте `uv run promvector-agent run`. SIGINT и SIGTERM завершают сбор с сохранением очереди. Запуск в той же папке параллельно с интерфейсом блокируется.

`uv run promvector-agent status` показывает ID и состояние при остановленном сборщике. `--data-dir` перед подкомандой меняет локальную папку. Журнал `agent.log` ротируется, аудит и измерения хранятся в `queue.sqlite3`. Операционная система защищает папку профиля и хранилище паролей. Учетные данные хранятся в Keychain, Windows Credential Manager или Linux Secret Service/KWallet. Для Linux нужна разблокированная служба ключей в пользовательской сессии.

Записи остаются в SQLite после подтверждения для локальной истории. Агент не удаляет очередь автоматически. При длительных сбоях контролируйте место на диске. Для замены компьютера завершите процесс и согласуйте перенос профиля и повторную регистрацию с администратором. Изменение ID площадки или адреса доставки создаёт новую область очереди. Предыдущие записи остаются в локальной истории и могут быть отправлены только при возврате к исходной конфигурации.

Для удаления завершите процесс, отключите автозапуск, отзовите агент на сервере и удалите приложение. Установщик Windows доступен в списке установленных приложений. Если требуется удалить локальные данные, предварительно сохраните нужную историю и удалите папку профиля, путь к которой показан в настройках. Записи с именем службы `PromVector Agent` можно удалить в штатном менеджере ключей ОС.

## Настройка источников

Для подключения выберите только разрешённые данные и подтвердите доступ. `equipment_id` и имена метрик должны соответствовать каталогу площадки. Каждая настроенная метрика может иметь собственную единицу. Пустое значение пропускается. Строковые и логические состояния остаются отдельными от числовых измерений.

- **Файлы.** Используйте UTF-8 CSV с заголовком или JSON-объект/массив объектов. В папке обрабатываются только непосредственные файлы CSV/JSON. Сохраняйте новый файл под временным расширением и переименовывайте после записи. Один файл ограничен 10 МиБ и 50 000 строками. Ошибка файла видна в статусе, остальные файлы могут обрабатываться. Хеш содержимого предотвращает повторный импорт того же файла в той же конфигурации.
- **SQL.** Укажите запрос, имя уникального идентификатора строки и столбец времени с часовым поясом. Запрос выполняется повторно с лимитом строк. Используйте индексированный временной диапазон и размер окна, покрывающий поток между опросами. Для PostgreSQL выдайте отдельной роли право `SELECT` на нужное представление и задайте DSN с `sslmode=verify-full` и доверенным CA. Сохраняйте DSN кнопкой «Учётные данные» или через `promvector-agent credential SOURCE_ID`.
- **OPC UA.** Включите подписку или задайте опрос. Для имени пользователя обязательны клиентский сертификат, закрытый ключ и закреплённый сертификат сервера. Разрешите клиенту только чтение заданных узлов. Храните ключ с ограниченными правами на файл.
- **Modbus TCP.** Указывайте нулевой адрес регистра, таблицу, тип данных, порядок слов и ID устройства. Подключайте только к разрешённому промышленному сегменту. Агент использует функции чтения holding и input.
- **SCADA / MES.** Адаптер реализует контракт `Collector.collect()` и `Collector.test()` и возвращает `Collection` из `Sample`. Конкретные системы подключаются через поддерживаемый протокол или отдельный документированный адаптер.

## Gemini

Включите модель и разрешение на метаданные в настройках, затем сохраните ключ через ОС. Для отправки измерений включите дополнительное разрешение. Перед каждым запросом интерфейс показывает подтверждение. Кэш зависит от версии промпта, модели, области агента и отправленного текста. В истории хранятся выводы модели, которые могут содержать детали предоставленного текста. Используйте только данные с разрешением на передачу в Google. [Google Gen AI SDK](https://github.com/googleapis/python-genai)
